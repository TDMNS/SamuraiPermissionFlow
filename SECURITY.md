# Security Policy

## Supported versions

Security fixes are evaluated for the latest code on `main` and the most recent tagged release. Older releases may not receive backported fixes.

## Reporting a vulnerability

Please do not disclose security-sensitive findings in a public issue.

Use GitHub's private vulnerability reporting feature from the repository's [Security page](https://github.com/TDMNS/SamuraiPermissionFlow/security) when it is available. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation.

If private reporting is unavailable, open a public issue requesting a private contact channel without including vulnerability details.

Reports will be reviewed as availability permits. This open-source project does not guarantee a specific response or remediation timeline.
